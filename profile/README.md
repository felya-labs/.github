# FELYA

> **Your hands. Anywhere on Earth.**

FELYA develops PATON, a haptic interface for intuitive interaction with robots and remote systems.

[![Discover FELYA](https://img.shields.io/badge/Discover-FELYA-111111?style=for-the-badge)](https://felya.com)
[![Explore the Brand Guide](https://img.shields.io/badge/Explore-Brand_Guide-ffffff?style=for-the-badge&labelColor=111111&color=555555)](https://brand.felya.com)

## Human intent, connected to the physical world

```mermaid
flowchart LR
    H["Human intent"] --> P["PATON<br/>Haptic interface"]
    P --> R["Robot or remote system"]
    R --> W["Action anywhere<br/>on Earth"]
    R --> P
    P --> H
```

PATON connects human dexterity with machines across distance. The interface is designed to make robotic interaction direct, embodied and useful in the real world.
